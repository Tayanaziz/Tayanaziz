### 🧪 Research Experience: Deepfake Audio Detection (FYP, 2025)
Final Year Project (team) and co-authored publication, supervised by Engr. Dr. Abdul Rehman Chishti
- Built a detection pipeline on the **Fake-or-Real (FoR)** dataset (195,000+ genuine and synthetic speech samples from Deep Voice 3, WaveNet and other TTS systems)
- Preprocessing: removed duplicate and corrupted files, normalized signals, zero-padded short clips, added Gaussian-noise augmentation
- Extracted MFCC and spectral features with Librosa; reduced 270 features to 65 with PCA (97% variance kept)
- Compared Random Forest, SVM (RBF), MLP and XGBoost; **Random Forest reached 92% accuracy**
- Open problems identified: generalization to unseen generators, real-world noise, imitation-based deepfakes, multilingual speech
